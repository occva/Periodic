## 1. 产品目标与范围

帮助个人集中管理软件、会员和服务订阅，快速了解有哪些订阅、何时到期、当前价格折合每月及每年多少钱，以及已经记录了多少实际付款。

| 编号 | 首版能力 |
| --- | --- |
| SCOPE-01 | 订阅新增、编辑、搜索、筛选、排序、复制、停用、恢复与删除。 |
| SCOPE-02 | 首页、图一形式的时间轴视图、表格视图、模板管理。 |
| SCOPE-03 | 手动确认续费、首次付款登记及付款历史维护。 |
| SCOPE-04 | 多币种分别汇总、系统本地提醒、上传本地服务图标。 |
| SCOPE-05 | 标准 CSV 与列映射导入、CSV 导出、包含历史和图片的完整备份恢复。 |
| SCOPE-06 | 本地服务模板库、从模板新建、自定义模板；模板不等于已拥有的订阅。 |
| SCOPE-07 | 周期订阅与终生一次性购买；终生项目不续费、不安排到期提醒、不计入周期费用预估。 |
| SCOPE-08 | 共享详情、手动新增/修改/删除订阅周期记录、按年份查看周期和付款历史，默认当年。 |

首版不包含账号、云同步、联网汇率、银行账单识别、实际支付、自动扣款、自动推进订阅周期或系统日历同步。截图中的第三方协作和动态功能不纳入首版。

## 3. 信息架构与全局行为

侧边栏依次包含 **首页、时间轴视图、表格视图、模板管理**，默认进入首页。偏好设置使用独立设置窗口，包含提醒、CSV 交换、备份恢复及数据清除。新增和编辑复用共享表单，不再设置单独的新增表单主页面。

- **NAV-01**：所有页面共享同一份数据，保存后同步刷新；取消表单不产生订阅或付款。
- **NAV-02**：支持 `Cmd+N` 新建、`Cmd+,` 偏好设置、`Cmd+F` 聚焦当前表格或日历搜索框，以及系统标准的保存和取消操作。
- **NAV-03**：关闭有未保存修改的表单时确认放弃；保存失败保留输入，保存中阻止重复提交。
- **NAV-04**：支持窗口缩放、最小化、尺寸恢复和侧边栏折叠。最小内容尺寸为 960 × 640 点；宽表格可横向滚动，工具栏空间不足时使用系统溢出菜单。
- **NAV-05**：表格与日历共享会话内搜索和筛选条件；统计页面按全库计算，不隐式继承这些条件。
- **NAV-06**：空库提供新建和导入入口，无搜索结果提供清除筛选入口；未知值显示“—”或明确状态，不显示成零金额或零天。
- **NAV-07**：新建菜单提供空白新建、从服务模板新建及 CSV 导入；Cmd+N 直接打开空白表单。模板管理是第四个主页面；从其他页面选择模板时可复用同一模板库 Sheet。
- **NAV-08**：所有详情入口定位同一记录，能够查看、编辑、续费（仅周期型）、补录付款、复制、停用/恢复和删除。被筛选隐藏的新增记录保存后提示“已保存，当前筛选下不可见”，提供查看或清除筛选，不擅自修改条件。
- **NAV-09**：列表名称链接、行双击/键盘打开、日历事件点/标签及临期卡片均进入同一订阅详情；列表单击行空白区仍用于选择，多选不受影响。直接编辑保留为右键和详情按钮。关闭详情恢复来源页筛选、滚动、分组折叠和选中状态。
- **NAV-10**：设置提供跟随系统、简体中文和 English 语言偏好，以及默认货币。默认货币只影响新建订阅和自建模板，不换算、不覆盖已有金额或模板建议币种。

## 4. 数据模型

### 4.1 订阅 `Subscription`

| 字段 | 约束与用途 |
| --- | --- |
| `id` | 持久化 UUID，用于付款关联、CSV 更新及备份恢复；名称不作为唯一键。 |
| `name` | 必填，去除首尾空白后不得为空；允许同名订阅。 |
| `symbolName` / `iconAssetID` | SF Symbol 名称及可选本地图片标识；图片优先，加载失败回退到符号。 |
| `category` | 服务类型，必填，默认其他。 |
| `managementState` | active（周期型显示订阅中，终生型显示使用中）或 inactive（已停用），默认 active，由用户维护。 |
| `billingKind` | recurring（周期订阅）或 lifetime（终生一次性购买），默认 recurring。 |
| `periodStart` | 可选开始日，仅保存年月日；周期型用于周期说明和剩余比例，终生型用于取得/开始使用日期。 |
| `expiryDate` | 周期型可选，当天有效、次日过期；终生型必须为空，显示“永久有效”而非“日期未知”。 |
| `cycleMonths` | recurring 必须为 1、3、6、12；lifetime 必须为空，不能用 0 或 999 作为终生周期。 |
| `periodAmount` | 价格金额，沿用此交换字段名；周期型为每周期价格，终生型为一次性价格。必填且初始为空，允许 0、不允许负数；不是已付款证明。 |
| `currency` | ISO 4217 币种代码，必填，默认 CNY。 |
| `note` | 可选多行备注。 |
| `reminderEnabled` | 单条提醒开关，默认开启，同时受全局开关和系统授权限制。 |
| `createdAt` / `updatedAt` | 创建和最后更新时间。 |

服务类型预置：工作学习、工具产品、影音娱乐、家庭日常、通讯服务、餐饮零食、其他。首版使用固定类型，导入时将外部分类映射到这些类型。

- **DATA-01**：周期起止日期均有值时，开始日不得晚于到期日。开始日属于辅助信息；首版有效性统一按管理状态及到期日判断，不提供独立的未来生效状态。
- **DATA-02**：支持选择本地 PNG/JPEG 图标，验证可解码并提供预览，复制到沙盒后统一管理，不依赖原文件持续存在；可替换、移除。未设置图片时使用 SF Symbols。
- **DATA-03**：剩余天数、到期状态、月均、年化及合计均为派生值，不作为可编辑字段或 CSV 导入事实。
- **DATA-05**：终生型 expiryDate/cycleMonths 必须为空、reminderEnabled 固定 false；remainingDays/remainingRatio/月均/年化均不适用，显示“—”。它不是未知到期日的周期订阅。
- **DATA-06**：表单切换为终生型时提示将清空到期日、周期和提醒，确认保存才生效；切回周期型默认月度，到期日保持空、提醒按周期默认开启，允许修改。所有类型变更不改写既有付款历史；禁止由到期日为空自动推断终生。

### 4.2 付款记录 `PaymentRecord`

| 字段 | 约束与用途 |
| --- | --- |
| `id` / `subscriptionID` | 付款 UUID 及所属订阅 UUID，一条订阅可关联多笔付款。 |
| `periodRecordID` | 可空，关联一条同属该订阅的周期记录；周期可有多笔付款，付款也可仅登记金额而不关联周期。 |
| `kind` | 首次付款、续费或补录付款。 |
| `paymentDate` | 实际付款日期，必填，不得晚于今天。 |
| `amount` / `currency` | 当次实付金额和币种快照；金额非负，0 表示已确认的免费或赠送周期。 |
| `periodStart` / `periodEnd` | 当次覆盖周期快照；续费时必填，补录历史可空；同时填写时开始日不得晚于结束日。 |
| `note` | 可选付款备注。 |
| `createdAt` / `updatedAt` | 创建和最后更新时间。 |

**DATA-04**：修改订阅当前价格、币种或周期，不改写付款历史的金额、币种和周期快照。实际支出按每笔付款自身币种统计。

### 4.3 设置和备份元信息

设置保存全局提醒开关、提前天数、时间以及窗口和视图偏好；系统通知权限不属于可备份设置。备份清单保存格式版本、导出时间、实体及图片清单，实体使用 UUID 关联。

业务日期以不含时区偏移的年月日保存；创建和修改时间以时间戳保存。

### 4.4 服务模板

服务模板只用于预填：稳定标识、名称、搜索别名、类型、后备符号/本地图标、建议计费类型、建议周期、可选建议价格与币种。内置模板来自随应用分发的离线目录；用户模板单独持久化。模板不包含管理状态、当前起止日期、付款、提醒调度或用户私密备注。用户模板及其图片属于完整备份和清空范围。

### 4.5 周期记录 `SubscriptionPeriodRecord`

| 字段 | 约束与用途 |
| --- | --- |
| id / subscriptionID | 周期 UUID 和所属订阅 UUID；订阅删除时级联删除其周期记录。 |
| source | initial、renewal、manual，说明来自首次完整周期、续费或手动补录，普通编辑不改来源。 |
| periodType | monthly、quarterly、semiannual、annual、custom、lifetime；为当次周期类型快照，不读取当前订阅类型替代。 |
| startDate / endDate | 开始日必填，结束日必填且 ≥ 开始日，首尾均包含；终生记录自动生成，未填写开始日时使用创建日，结束日默认 `2099-12-31`，允许用户在历史中修改。该结束日只用于历史展示，不是订阅到期日。 |
| quotedAmount / currency | 可选的本期价格快照，币种必填；金额未知为 null，0 是明确的零元价格。它不代表已付。 |
| note | 可选当次周期备注。 |
| revision / createdAt / updatedAt | 并发版本及审计时间。 |

周期记录描述一段使用/覆盖时间，付款记录描述实际付钱。两者一对多可选关联，付款继续保存其自身金额、币种及覆盖日期快照；改周期记录不改旧付款。表中“次数”按全量周期起始日、创建时间、UUID 排序生成序号，不是付款笔数，也不是数据库主键。

## 5. 日期、状态与费用规则

### 5.1 状态与剩余天数

**RULE-01**：管理状态与到期状态独立。到期不会自动停用或续费；停用不删除日期和历史。

表格“状态”列使用综合展示：管理状态为停用时显示“已停用”；否则周期订阅 `D < 0` 时显示“已过期”。这只是派生展示，不把持久化管理状态从 active 改写为 inactive。

**RULE-02**：剩余天数 `D` 为到期日减去今天的公历自然日数，以当前系统时区确定今天，不使用秒数除以 24 小时计算。改变时区不修改记录的年月日。

| 条件 | 到期标签 | 展示 |
| --- | --- | --- |
| 终生型 | 永久有效 | 无到期日和天数，不安排提醒；停用仍显示真实类型。 |
| 周期型到期日为空 | 日期未知 | 天数为“—”，不安排提醒。 |
| `D < 0` | 已过期 | 显示负数天数和红色提示。 |
| `D = 0` | 今天到期 | 显示 0 天和醒目提示。 |
| `1 ≤ D ≤ 7` | 7 天内到期 | 黄色或橙色预警。 |
| `8 ≤ D ≤ 30` | 30 天内到期 | 较低级别预警。 |
| `D > 30` | 正常 | 正常状态样式。 |

标签互斥，避免用“本周／本月到期”表示滚动 7／30 天。已停用条目弱化展示，但保留真实到期状态。

**RULE-03**：应用启动、回到前台、系统日期或时区改变及运行中跨越午夜时刷新派生状态。过期后保留原日期，直到用户编辑或续费。

**RULE-04**：周期型起止日期齐全时可显示剩余比例：`clamp((D + 1) / 周期总自然日数, 0, 1)`，总天数包含首尾两天。开始日未知或终生型省略比例条；比例条不参与费用计算。

### 5.2 当前有效与预估费用

**COST-01**：当前有效条目 = active 的终生项目，或 active 且到期日已填写、`D ≥ 0` 的周期订阅。周期费用预估只统计后者；终生、无日期周期型、已过期及已停用项目不进入周期主预估。有效数量与参与预估数量分别展示，不混为一项。

**COST-02**：周期型只录入每周期金额和币种。设周期月数为 `M`，月均费用＝周期金额÷`M`，年化费用＝周期金额×12÷`M`。过期周期记录仍可显示单条折算金额，但不因此进入主合计。终生一次性价格不折算月均/年化，也不作为终生累计实付；实际支出仍须登记付款。

| 价格示例 | 月均 | 年化 |
| --- | --- | --- |
| CNY 88／年度 | CNY 7.33 | CNY 88.00 |
| CNY 120／半年 | CNY 20.00 | CNY 240.00 |
| CNY 43.20／季度 | CNY 14.40 | CNY 172.80 |
| USD 10／月度 | USD 10.00 | USD 120.00 |

**COST-03**：金额使用十进制表示，按币种小数位数校验和展示。中间计算保留精度，汇总后四舍五入，不累加已经舍入的行显示值；CNY、USD 通常保留两位，JPY 为整数。

**COST-04**：不同币种分别汇总并显示代码，不直接相加，不换汇。卡片使用“月均预估／年化预估”，明确为当前价格折算，不代表账单或实际付款。

### 5.3 已记录实际支出

**COST-05**：按付款日期处于选定日期范围内的付款记录汇总，包含首尾日期，并按付款币种分别展示。订阅后来过期、停用或调价，不影响已记录历史实付。

**COST-06**：补录、纠正或删除付款后更新实际支出。没有记录时显示“尚无付款记录”，不推断用户从未付款；实际支出与预估分开显示。

## 6. 订阅维护与续费

### 6.1 新增和编辑

- **EDIT-01**：共享表单包含基本信息、当前周期、提醒及备注，按第 4 节校验，实时显示只读月均和年化预览。
- **EDIT-02**：新建提供默认未勾选的“同时登记首次付款”。勾选后填写付款日期、金额和币种，可从当前价格预填并修改；未勾选则不生成付款。订阅和首次付款在同一事务中保存。
- **EDIT-03**：编辑当前价格或日期不隐式生成付款；实际支出通过续费或补录登记。字段错误应定位到输入项，不允许部分保存。
- **EDIT-04**：详情内付款历史按付款日倒序，受详情历史区年份筛选控制，默认当年并可切全部；支持补录、纠正、删除。修改或删除付款不自动回退当前订阅日期、也不自动删除周期记录。
- **EDIT-05**：新增/编辑包含计费类型。选择终生时价格标签改为“一次性价格”，显示永久有效说明，隐藏无意义的周期/到期/提醒输入；可选登记首次付款继续可用，未勾选不产生实际支出。

### 6.2 手动续费

**RENEW-01**：续费表单包含实际付款日期、金额与币种、新周期开始及到期日、备注。付款日期默认今天，实付默认当前价格，允许修改。

**RENEW-02**：日期按以下规则预填，并允许用户调整：

- 原到期日不早于今天：新开始日为原到期日次日，新到期日为原到期日增加一个计费周期。
- 已过期或日期未知：新开始日为今天，新到期日为开始日增加一个周期后减去一天，使首尾两天均包含在覆盖区间中。
- 按公历月份相加；目标月份没有对应日时，取该月最后一天。例如有效月度订阅原到期日 2027-01-31，续费后预填 2027-02-01 至 2027-02-28。
- 已过期月度订阅在 2026-09-22 续费，预填 2026-09-22 至 2026-10-21。
- 停用条目允许续费，表单说明保存后恢复订阅中。

**RENEW-03**：一次事务内新增一条周期记录和与之关联的付款、更新当前周期日期并设为订阅中，任一步失败全部不提交；重复点击或重试只产生一条周期和一笔付款。本期价格快照可保存当前报价，实付保存用户确认金额，两者允许不同。

**RENEW-04**：本次实付不自动覆盖未来每周期价格、币种或周期。如未来价格发生变化，用户在编辑订阅中明确修改；已有付款快照不变。

**RENEW-05**：终生型不提供续费入口，接口也拒绝对终生型续费。重复购买或历史费用通过补录付款登记；需要变为周期型时先显式编辑计费类型。

### 6.3 复制、停用和删除

- **LIFE-01**：复制打开预填的新建表单，名称默认追加“副本”，沿用当前字段和图标；保存后使用新 UUID，不复制周期/付款历史，首次付款默认不勾选。即使草稿日期完整，也不自动复制原周期记录。
- **LIFE-02**：停用保留数据和历史、取消待发送提醒并移出预估合计；恢复仅修改管理状态，有效性继续按日期判断。
- **LIFE-03**：支持单条、多选删除及先选择已过期条目再批量删除。永久删除前列明订阅数、周期记录数及付款数，确认后级联删除这些记录并重新统计。
- **LIFE-04**：删除后清理通知和不再被任何条目引用的图标；失败保留原数据，不出现半删除。停用不清理图片。

### 6.4 共享订阅详情

- **DETAIL-01**：详情顶部展示图标、名称、管理状态，提供编辑、设置当前周期、续费（仅周期型）、更多操作与关闭。单一详情组件由列表/日历/统计复用，不新增第四个主 Tab。
- **DETAIL-02**：基础信息区显示周期/一次性价格及币种、当前开始日和到期日、计费方式、服务类型、提醒、备注；截图“消费金额”改用明确的价格名称。实际累计支出和所选年支出另按付款计算，无付款显示尚无付款记录。
- **DETAIL-03**：计算区显示到期状态、剩余天数及比例、月均预估、年化预估，全部只读并复用共享规则；终生显示永久有效，费用折算/天数不适用。不从截图示例数字或其“自动计算”提示推断业务数据。
- **DETAIL-04**：下方历史区包含“周期记录 / 付款记录”两个局部视图；上方共同年份栏为上一年、年份选择、下一年、回到当年、全部年份，默认系统当前公历年。顶部当前资料与价格不随历史年份改变。
- **DETAIL-05**：周期表列为次数、周期类型、开始日、结束日、本期价格与币种、关联付款数、备注、操作；价格未知显示“—”，已确认零元显示 0。支持在表格行内直接编辑周期、日期与金额；编辑使用独立草稿及明确保存/取消，不逐单元格产生部分写入。另支持手动新增、删除、查看关联付款及“应用到当前设置”。
- **DETAIL-06**：年份筛选按周期与选定年区间相交：start ≤ 年末且 end ≥ 年初；跨年周期在涉及的各年可见、显示完整原日期及“跨年”，但底层只有一条记录。终生记录只归开始年份，不在以后每年重复列出。付款视图始终按付款日所属年份，不能把跨年价格按年自动摊销成实付。
- **DETAIL-07**：年份菜单包含当年及现有周期覆盖/付款涉及的年份，另可切空年份和全部；当年无记录显示当年空态与查看全部入口，不自动切旧年份。同一详情打开期间保留手选年份，关闭后重新进入默认当年；默认“当年”模式跨元旦更新，手选固定年份不变。
- **DETAIL-08**：年份切换不重编号周期、不清空未保存草稿、不修改提醒/主视图筛选。保存到其他年份时提示“已保存至 YYYY 年/跨年记录”，允许跳转但不擅自切换；历史为空不代表当前订阅无效。

### 6.5 手动周期维护

- **PERIOD-01**：支持手动新增当次周期，选择月度/季度/半年/年度/自定义日期/终生，填写开始和结束、本期价格、币种及备注。预置类型可给结束日建议，但允许独立调整起止；手动覆盖不强制等于整月。“自定义日期”描述这条历史区间，不改变当前费用折算用的 1/3/6/12 月计费方式。
- **PERIOD-02**：新增周期默认不登记付款；可勾选“同时登记付款”并填写实际付款日、实付和币种，两者原子保存。仅补录周期不增加实际支出；未来周期可记录，但不得登记未来付款。
- **PERIOD-03**：普通新建/从模板创建且当前起止完整时，同事务记录一条 initial 周期；终生有开始日时记录终生 initial 周期。当前日期不完整不生成伪历史。复制、CSV 和普通修改当前字段不自动追加历史；如要保存周期历史，使用明确的周期记录动作。首次付款存在时可关联本次 initial 周期，否则允许不关联。
- **PERIOD-04**：手动历史新增/编辑/删除默认不修改订阅当前字段，不重排提醒。“应用到当前设置”单独预览并确认，仅复制该记录的类型/起止及对应周期；自定义区间必须选择当前计费周期。价格默认保留，可明确勾选使用本期价格；管理状态默认保留，恢复 active 需单独选择。应用不生成新周期或付款，不建立后续自动同步关系。
- **PERIOD-05**：历史重叠允许但提示，用户确认后保存；同内容重复记录提示可能重复，不按日期自动合并。相邻覆盖日期采用结束日包含的规则，默认下一期开始为前期结束次日；截图相接日期不作为排除校验依据。
- **PERIOD-06**：删除周期先显示关联付款数，默认只删除周期并解除关联、保留付款及其快照，也保留当前订阅日期；如要删付款必须另行确认。改周期日期/类型不改历史付款快照，解除关联不删除实付。
- **PERIOD-07**：纠正历史周期可以保留与当前订阅不同的历史类型（例如过去年度、现在月度或终生），不得用当前价格或周期批量覆盖。周期、付款、订阅三者任一事务失败全部回滚；并发修改保留草稿并提示重载。

## 7. 表格视图

- **TABLE-01**：列顺序及列名固定为服务名称、状态、服务类型、到期时间、剩余时长、账户状态、周期、消费金额、按月计算、按年计算、备注。日期展示为 `YYYY/MM/DD`，长文本可通过悬停或详情读取；终生行按 DATA-05 显示。剩余时长进度条按固定 100 天刻度展示绝对剩余天数，`clamp(D / 100, 0, 1)`，不使用各条目不同的起止区间作为分母；100 天及以上满格，99 天为 99%，今天到期及已过期为空。
- **TABLE-02**：名称搜索忽略大小写和搜索词首尾空白；按管理状态、到期状态、服务类型、计费类型、币种组合筛选，维度之间为“且”关系，默认全部。
- **TABLE-03**：默认按剩余天数降序排列，即较大的正数在前、零居中、负数在后；无日期置后，同值按名称及 UUID 稳定排序。支持日期、剩余天数和年化金额升降序；日期及天数排序时无日期始终置后。
- **TABLE-04**：跨币种金额排序先按币种代码分组，再在组内排序；单币种筛选下直接按金额排序，不跨币种比较经济价值。
- **TABLE-05**：工具栏提供新建、搜索、筛选、排序和多选操作；名称链接、双击或选中单行后 Return 打开详情，单击空白区选择；右键提供详情、编辑、续费、复制、停用或恢复、删除。
- **TABLE-06**：底栏显示当前结果数／全库总数，对结果中的有效周期订阅按币种汇总，并注明“周期订阅预估”。同时展示未参与预估的停用、active 终生、active 过期周期、active 无日期周期数量，按此优先级互斥分类；五项合计等于结果数。无符合条件时显示“无参与预估的周期订阅”。
- **TABLE-07**：提供“全部项目、使用中、已过期、已停用、终生”快捷视图，名称与当前条件一致。“已过期”默认只筛 active 周期型且 D < 0；其他复杂组合继续使用筛选器。快捷视图作用于共享筛选，筛选栏始终展示生效条件，避免隐式条件。
- **TABLE-08**：提供平铺、按服务类型、按管理状态三种展示。分组支持折叠、组内数量和按币种小计；默认固定分组顺序，组内沿用排序。折叠不改变筛选、底栏或导出范围；跨组多选仍按实际选择 ID 操作。
- **TABLE-09**：支持列显示/隐藏、列宽调整、恢复默认；名称列不可隐藏。分组和列配置为视图偏好，不能改写订阅字段。金额排序时终生的“不适用”置后，不当零值排序。

### 7.1 从服务模板新建

- **CATALOG-01**：从新建下拉、空库及“添加服务”入口打开同一服务库。提供全部、按类型查看、内置/自建来源筛选、名称/别名搜索和空白新建；服务库搜索独立于 Tab1/Tab2 的记录筛选。
- **CATALOG-02**：卡片显示名称、图标、类型，可提示已添加数量；已添加仍可再次创建，不按名称去重或禁用卡片。点击模板只创建草稿，不立即写订阅或付款。
- **CATALOG-03**：模板预填名称、类型、图标、计费方式、币种及可选建议金额，缺金额保持空、起止日期保持空；用户确认真实价格和日期后保存。首次付款默认不勾选，不把截图数值当当前价格。
- **CATALOG-04**：内置模板离线只读；支持新建、复制为自建、编辑及删除用户模板。可从现有订阅“保存为模板”，先预览将复制的字段，排除日期/历史/私人备注。模板改名或删除不修改已创建记录。
- **CATALOG-05**：图标来自随应用提供的合规本地资源、SF Symbols 或用户上传；无可用品牌图标时回退符号，不联网拉图。自建模板图标可与订阅共享，只有无任何引用后才清理。
- **CATALOG-06**：首屏无用户订阅时仍可浏览内置目录；目录不是演示业务数据，不计入任何订阅数量或费用。服务库支持无结果、加载失败及重试；自建模板包含在完整备份，CSV 仅交换当前订阅。
- **CATALOG-07**：模板管理在页面内提供模板库侧栏，可新增、重命名和删除自定义分类。删除分类不删除模板，关联模板回到“其他”；内置分类只读。
- **CATALOG-08**：内置模板优先使用随应用打包的品牌图标；自建模板可由用户主动通过 Apple Search API 选择图标。没有设置图标时才使用稳定的 SF Symbol 占位，不把 SF Symbol 当品牌图标离线回退。
- **CATALOG-09**：模板管理支持把任意模板拖到左侧内置分类或自定义分类。内置模板的名称、计费建议和图标仍只读，但分类整理作为本地覆盖持久化；移动时不复制模板。删除自定义分类后，其中全部模板回到“其他”。

## 8. 时间轴视图

### 8.1 布局

- **TIME-01**：采用参考图一形式，横轴是连续日期，每个订阅独占一行，到期日在横轴的位置决定事件锚点。只展示当前周期到期事件，不展开付款历史或预测未来续费事件。
- **TIME-02**：顶部使用两级时间刻度：1 个月显示月份与逐日刻度，3/6 个月及 1 年显示月份与逐周日期，3/5 年显示年份与逐月刻度；所选范围必须完整适配当前内容宽度，内容区网格与下层精细刻度逐一对齐。红色今天线和日期圆点在跨日后更新；今天位于月份中间时，圆点始终显示日号，不复用当前缩放级别的月份标签。
- **TIME-03**：事件采用紧凑的内容自适应宽度、最大宽度和统一行高，以便同屏浏览更多服务；内容包含图标、名称、剩余天数、固定宽度的剩余比例进度条和到期标签。到期日只决定事件锚点位置，不使用起止日期改变事件自身宽度；文字可延伸到锚点右侧，但不得为迁就文字移动实际日期位置。
- **TIME-04**：条目按到期日升序及稳定次序排列，仅展示满足当前搜索和筛选的记录。每行独立，避免标签互相覆盖。

### 8.2 浏览与操作

- **TIME-05**：提供 1 个月、3 个月、6 个月、1 年、3 年、5 年可见范围，首次进入默认 5 年并将今天居中；切换范围后完整范围适配窗口宽度，通过前一范围/后一范围浏览历史和未来，条目仅纵向滚动。
- **TIME-06**：1 个月主要显示日刻度；3 个月显示周刻度和月份；1 年及 5 年显示月刻度和年份。日期坐标按真实自然日间距计算，不能把不同长度月份视为相同天数。
- **TIME-07**：切换范围保持中心日期；“今天”按钮将今天居中。范围外条目在对应边缘展示方向提示，点击后将其到期日定位到中央。
- **TIME-08**：提供“无日期（数量）”入口，数量受筛选影响；点击打开列表，可查看和补充日期，不伪造时间轴位置。
- **TIME-09**：点击日期标记或标签打开与列表共用的详情，可编辑当前资料、手动维护周期历史和续费；历史区默认当年。主轴当前浏览年份不传入详情年份，首版不支持拖拽修改到期日。
- **TIME-10**：提供前一范围/后一范围按钮，按当前范围平移 1、3、12、60 个公历月；“今天”回到当前日期。范围外方向提示仅定位该订阅，不修改日期。
- **TIME-11**：时间线下方提供临期卡片区，可选未来 7/15/30 天、默认 15；条件为 recurring + active + 0 ≤ D ≤ N，含今天和未来第 N 天。受本页共享搜索筛选影响，但不受当前可见年份/水平位置限制；卡片数与相同条件列表一致。
- **TIME-12**：临期卡片显示图标、名称、到期日、剩余天数、准确到期标签，提供详情、续费和定位。无匹配时显示“当前条件下未来 N 天无到期项目”；不为凑卡片插入示例数据。
- **TIME-13**：终生项目不占时间轴日期位置，也不算“无日期”；提供“终生（数量）”独立入口查看和编辑。筛选结果满足“有日期周期型 + 无日期周期型 + 终生 = 总结果数”；仅终生时显示永久有效说明及列表入口。
- **TIME-14**：工具栏支持按服务类型、管理状态和计费类型筛选，并提供一键清除；临期区可通过标题旁图标收起和展开，收起不改变筛选或临期范围。

## 9. 首页

- **STAT-01**：展示全库总数、当前有效、已过期、已停用、日期未知数量。先分离 inactive，再分 active 终生或未过期周期型为有效、过期周期型为过期、无日期周期型为未知；四类之和等于总数。有效卡片标明其中周期型与终生各多少，终生不能进入未知。
- **STAT-02**：按币种展示全库有效周期订阅月均和年化预估及参与条目数，明确不受表格及日历筛选影响，终生价格不入预估。
- **STAT-03**：即将到期列表采用与 TIME-11 相同的 7/15/30 天规则、默认 15，统计范围为全库、不继承表格/日历筛选；按日期排序，今天优先，支持详情和续费。范围选择会话内由两个页面共享。
- **STAT-04**：分类图按服务类型汇总有效周期订阅年化金额，一次选择一个币种，默认 CNY，展示金额及占比；终生不参与，无数据或总金额为零时显示空态。
- **STAT-05**：已记录实际支出支持本月、本年和自选日期范围，默认本年，按币种汇总并提供付款明细。
- **STAT-06**：数量卡片支持查看对应全库记录列表，分类图选择某类型可查看该币种下参与计算的有效周期记录，实付金额可查看该币种和日期范围的付款。下钻沿用本次统计口径，不改动其他 Tab 筛选；记录变动时明细及合计一起刷新。
- **STAT-07**：终生首次付款和补录付款进入实付，金额按付款快照统计；只填一次性价格但未登记付款时，仍显示尚无付款记录。分类年化图始终排除终生。

## 10. 到期提醒

- **NOTIFY-01**：全局提醒默认关闭，首次主动开启时请求系统授权；单条开关默认开启，仅在全局开启且已获授权后生效。拒绝授权不阻断其他功能，设置页提供系统设置指引。
- **NOTIFY-02**：默认到期前 7、3、1 天及到期当天本地时间 09:00 提醒。全局可设置不重复的非负提前天数和时间；单条只提供开关，不提供独立时间表。
- **NOTIFY-03**：只为 recurring、active、单条提醒开启且有日期的条目安排未来提醒；终生始终不安排。已过去的提醒时刻跳过、不集中补发。内容包含名称、到期日期和剩余天数。
- **NOTIFY-04**：当前订阅保存/改期、应用周期到当前、续费、停用、删除、提醒设置修改及恢复后核对旧请求并重排。仅改历史周期或切详情年份不改提醒。使用稳定标识去重；点击通知开详情，记录不存在回总览。
- **NOTIFY-05**：启动、回到前台及系统时区改变时核对授权和待发送请求。调度失败显示状态并允许重试，不回滚已成功保存的订阅或付款。
- **NOTIFY-06**：已提交的通知可由系统在应用退出后处理；实际送达受授权、专注模式、休眠及系统策略影响。遇系统待发送容量限制时优先安排最近提醒，后续启动补齐，并显示尚未调度数量；不承诺无限后台运行。

## 11. CSV 导入导出

### 11.1 标准格式

**CSV-01**：标准 CSV 表示当前订阅，不包含周期/付款历史、图片文件和全局设置。标准列为：

```text
id,name,symbolName,category,managementState,billingKind,periodStart,expiryDate,cycleMonths,periodAmount,currency,note,reminderEnabled
```

- 导出 UTF-8 并带 BOM，导入兼容有无 BOM；第一行为列名。
- 日期输出 `YYYY-MM-DD`，空日期留空；金额无币种符号和千位分隔符，币种单列。
- 管理状态输出 active/inactive；billingKind 输出 recurring/lifetime。周期型周期输出 1、3、6、12；终生型周期/到期留空、提醒输出 false，periodAmount 表示一次性价格。CSV 保留统一价格列名，不额外生成月均/年化列。
- 正确转义字段中的逗号、双引号和换行。图片条目导出后备 SF Symbol，完整恢复图片使用备份包。
- 默认导出全库，表格页面可明确选择当前筛选结果，导出前显示数量。

**CSV-02**：为降低表格软件公式执行风险，导出用户文本若以 `= + - @` 或单引号开头，增加一个前置单引号；标准模板导入模式还原对应的一层转义，其他外部 CSV 默认保留原文。导入预览明确展示该文本处理模式并允许切换。

### 11.2 导入规则

- **CSV-03**：流程为选择文件、识别或映射列、映射枚举值、预览校验、确认导入、展示结果。标准列自动识别，外部列允许手动映射和忽略。
- **CSV-04**：名称、计费类型、价格金额、币种必须从映射或明确默认取得；周期型还必须有合法周期。缺失 ID 时新建 UUID；旧格式无 billingKind 列的新建默认 recurring 并在预览展示，不把空日期猜成 lifetime；更新时未映射 billingKind 保留原值。类型默认其他、状态 active、周期型提醒默认开启，终生固定关闭。
- **CSV-05**：外部类型、状态、周期须映射到合法值；“已过期”不是管理状态。忽略剩余天数、月均/年化派生列，导入当前字段不生成周期或付款历史。
- **CSV-06**：支持 `YYYY-MM-DD` 和 `YYYY/MM/DD`，拒绝不存在的日期及含糊的月日顺序。金额可去除与确定币种一致的前缀及规范千位分隔符；`$`、`¥` 等符号不能单独确定币种，必须映射币种列或显式选择默认币种。冲突或无法确定的金额报错。
- **CSV-07**：逐行预览原行号、错误字段、默认值和处理结果；错误需修正或由用户明确排除对应行，禁止静默跳过后继续导入。
- **CSV-08**：与数据库 UUID 相同默认跳过，可明确更新；仅改已映射字段，未映射字段、周期/付款历史和图片保持不变，映射空可选值表示清空。同文件重复 UUID 报冲突；同名不同 ID 不合并，无 ID 重复导入可能重复新增，须在预览提示。
- **CSV-09**：本次选择导入的数据以单次事务提交，失败不写入部分数据。成功后刷新页面和提醒，报告新增、更新、跳过、排除数量。
- **CSV-10**：外部“终生/永久/一次性”须明确映射到 billingKind=lifetime，不映射成超长周期。终生行有到期日、周期或开启提醒时逐行报错，预览允许明确选择清空不适用字段；类型更新不得在后台悄悄丢弃原日期。

## 12. 完整备份、恢复与清除

- **BACKUP-01**：使用单个 ZIP 备份包，包含版本清单、订阅（含计费类型）、周期记录、付款及其可选周期关联、用户服务模板、图片和设置。结构化内容用 JSON，金额为十进制字符串，日期为 YYYY-MM-DD，保留全部 UUID 及关联；内置模板仍随应用分发。
- **BACKUP-02**：导出读取一致的数据快照，写入失败不把不完整文件报告为成功。首版备份和 CSV 为可读文件，不提供加密备份。
- **BACKUP-03**：恢复采用整体替换，不与现库合并。先在临时位置校验版本、字段、UUID 唯一性、付款引用、图片可读性和安全相对路径；损坏、缺失图片、不兼容版本或路径越界均拒绝恢复。
- **BACKUP-04**：验证通过后展示将替换和恢复的订阅、周期记录、付款、用户模板及图片数量，提供先备份入口，确认后替换。操作期间暂停其他编辑；失败保留原数据库、图片、模板与设置，不产生混合状态。
- **BACKUP-05**：恢复成功后刷新页面、移除旧提醒并重新调度。系统通知权限使用当前设备状态；备份不包含系统权限、绝对文件路径或通知请求标识。
- **BACKUP-06**：清除全部数据使用独立确认，列明订阅、周期记录、付款、用户模板、图片及设置并提供备份入口；成功后取消通知、恢复空库和默认设置，不尝试撤销系统通知授权。随应用分发的内置模板继续可用，不属于用户记录。

## 13. 视觉与质量要求

- **UI-01**：采用 macOS 原生侧边栏、工具栏、表格和 Sheet。玻璃主要用于导航、浮层及适合的控件容器，内容层保持文字清晰，避免逐单元格叠加玻璃。
- **UI-02**：支持浅色、深色、增加对比度和减少透明度；状态必须有文字或图形辅助，不能只靠颜色。
- **UI-03**：图标统一显示尺寸，金额按位对齐，长名称不覆盖日期锚点或其他行。设置提供货币代码／符号显示切换，默认代码；中文界面下共享符号须追加币种名称消歧，例如 `¥100（人民币）`、`¥100（日元）`。该偏好不得改写币种或金额。
- **UI-04**：关键流程支持键盘与 VoiceOver；时间轴标记可访问名称包含服务名、日期和状态。减少动态效果开启时弱化缩放及定位动画。
- **UI-05**：使用 macOS 26 原生 Liquid Glass：Sidebar、Toolbar、Sheet 和标准表单保持系统材质；首页卡片、模板卡片、时间轴事件和搜索结果等自定义表面使用成组 Glass Effect，不叠加不透明背景或重复模糊层。
- **UI-06**：模板管理的内部侧栏宽度稳定，内容区从顶部和侧栏分隔线后立即开始，不允许因嵌套导航产生空白列；金额输入和货币选择保持独立宽度，在最小 Sheet 尺寸下不得重叠。
- **QA-01**：日期、状态、费用使用共享业务规则，保证三个页面同口径；首版文案为简体中文，名称及备注支持 Unicode。
- **QA-02**：导入导出、备份恢复提供进度或忙碌状态，错误说明具体原因并保护现有数据。
- **QA-03**：使用至少 1,000 条订阅和 10,000 条付款检查搜索、筛选、统计及滚动，避免一次性绘制所有时间轴内容或反复全量统计导致持续卡顿。
- **QA-04**：开发测试样例与用户数据库分离，正式首次启动为空库。
