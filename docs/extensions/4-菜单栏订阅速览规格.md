# 菜单栏订阅速览规格

> 版本：1.0｜日期：2026-09-23｜状态：第一阶段已实现，后续联动与完整验收待完成。
> 依赖：[需求文档](../requirement.md)、[架构说明](../architecture.md)、[扩展规格总则](README.md)。

## 1. 产品定位

Periodic 在 macOS 顶部菜单栏提供订阅速览。用户点击状态项后，可在不切换当前工作的情况下查看订阅概况、即将到期项目和分币种费用，并快速进入主窗口的对应详情。

菜单栏是只读速览和快捷入口，不是缩小版主应用：

- 不在弹层内编辑、续费、删除、导入或处理冲突；
- 不复制日期、状态、费用和筛选算法；
- 不把通知提醒等同于菜单栏展示；
- 不把 Periodic 改成无 Dock 图标的纯菜单栏应用。

## 2. 场景与生命周期决策

使用 SwiftUI `MenuBarExtra`，采用 `.menuBarExtraStyle(.window)` 展示可滚动的原生弹层。现有 `WindowGroup` 继续作为启动时显示的主窗口，应用保持普通 Dock 应用和正常激活策略，不切换为 `.accessory`。

设置中的“在菜单栏显示 Periodic”控制状态项是否插入，默认开启。该设置只影响当前设备；关闭后不删除任何订阅，也不关闭已打开的主窗口。启用菜单栏项目时，即使用户关闭最后一个主窗口，Periodic 仍在后台运行并维护状态项；退出应用必须使用 Cmd+Q、应用菜单或速览底部的“退出 Periodic”。

如 SwiftUI `openWindow` 无法在所有受支持系统状态下可靠激活主窗口，只允许增加一个负责激活应用和定位既有窗口的窄 AppKit adapter，不能让 AppKit 承载查询或业务状态。

## 3. 状态项

### 3.1 外观

- 使用 Periodic 的应用图标，确保状态项与 Dock、Finder 中的产品身份一致。
- 默认只显示图标，避免长期占用菜单栏宽度。
- 有 1～99 个今天到期的有效周期订阅时，在图标旁显示数量；超过 99 显示 `99+`。
- 数量为 0、数据正在首次载入或读取失败时不显示伪造数字。
- 颜色不是状态信息的唯一载体；增加对比度模式下仍使用图标与文本数量表达。

状态项的 VoiceOver 标签为“Periodic，今天有 N 项到期”；今天没有到期项目时为“Periodic，今天没有到期项目”；读取失败时为“Periodic，订阅信息暂不可用”。当天口径不随弹层的 7/15/30 天选择改变。

### 3.2 点击行为

- 单击打开或关闭速览弹层。
- 弹层打开时不自动激活主窗口，不抢夺其他应用的前台焦点。
- 点击订阅、查看全部、新建、设置或打开 Periodic 时，关闭弹层，激活应用并路由到明确目标。
- Esc 关闭弹层；Tab 和方向键可到达全部交互项。

首版不增加不同的右键菜单，避免左右键行为分叉。系统对状态项的重新排列行为保持原生。

## 4. 弹层内容

弹层宽度 320 点；临期记录最多显示 5 条，费用区展示订阅数据中出现的全部币种。内容较少时高度随内容自适应，超过 560 点时整个内容区滚动，既不产生底部空白，也不让币种明细超出屏幕。使用系统材质、按钮和语义颜色，不叠加自定义窗口背景。

### 4.1 顶部摘要

顶部不显示应用名和刷新时间，避免重复菜单栏状态项已经表达的应用身份。内容以一行可点击的有效订阅摘要开始：

- 当前有效总数；
- 点击摘要打开主窗口首页；
- 周期型、终生、已过期、已停用和日期未知的拆分留在主窗口，不占用菜单栏速览空间。

点击某项数量，打开主窗口表格视图并应用等价筛选。筛选是目标窗口自己的会话状态，不写成全局偏好，也不修改其他已打开窗口。

### 4.2 即将到期

- 范围使用设置中的 7、15、30 天设备偏好，弹层只显示当前范围，不重复放置分段选择器。
- 口径复用 `SubscriptionAnalytics.upcomingItems(within:)`：只包含 active、recurring、有到期日且剩余天数为 `0...N` 的记录。
- 按到期日、名称和 UUID 稳定排序，弹层最多直接显示前 5 项。
- 每行显示服务图标、截断后的名称、到期日期及“今天到期 / N 天后”；完整名称通过帮助文本和 VoiceOver 提供。
- 点击行打开主窗口中的订阅详情；“查看全部”打开首页的即将到期区域或时间轴，并保留所选范围。
- 终生、停用、已过期和无到期日期记录不混入临期列表。

名称在菜单栏界面最多显示 30 个字符；截断只影响展示，不修改原始名称。

### 4.3 费用速览

- 复用首页预估费用口径，只统计当前有效、周期明确的 recurring 订阅。
- 按币种分别显示月均和年化，禁止跨币种相加或隐式换汇。
- 按币种代码稳定排序并展示全部币种的月均金额，原币种金额保持不变，不能因菜单栏空间截断币种明细；币种行下方使用 `GET https://api.frankfurter.dev/v2/rates?base={默认货币}` 的多来源央行参考数据换算到默认货币，显示“本月花费约 N”。请求只发送基准币种代码，不发送订阅名称、金额或备注；不限制 `quotes`，把服务端返回的完整币种汇率快照缓存在本地。快照有效期 6 小时，网络失败时可使用最后一份缓存并明确标记。所有金额均为默认货币时不联网，并说明无需换算。换算不修改原始币种和金额。年化信息通过顶部首页入口查看。
- 设置窗口提供独立“汇率”页。搜索框位于页面内容区，不占用设置窗口的 Tab 工具栏；页面展示所选基准货币对应的完整本地快照，支持按币种代码或本地化名称搜索及手动刷新。
- 完整汇率表每行提供常用货币复选框，并可切换“全部 / 已选”范围；页面打开时默认显示“已选”。默认选中 CNY、USD、JPY、KWD，且至少保留一种。基准货币使用下拉菜单，只列出已勾选的常用货币并独立于新建订阅的默认货币。取消当前基准货币时自动改用其余已选货币；改变基准货币时读取或下载该基准自己的快照。手动刷新失败保留已有列表并展示错误。
- 新建订阅、模板、历史记录和币种筛选菜单使用常用货币集合；已有数据使用的币种即使不再勾选，也继续作为当前值显示，避免偏好变更破坏编辑和读取。
- “在菜单栏显示预估金额”是当前设备隐私偏好，默认开启。关闭后保留订阅数量和到期信息，费用区域显示“金额已隐藏”。
- 终生一次性价格不进入月均或年化；实际付款不与预估费用混合。

### 4.4 底部操作

不设置常驻底部操作栏。点击有效订阅摘要进入主窗口，点击临期行进入详情；新建、设置与退出继续使用主窗口、应用菜单和系统快捷键，避免在速览中复制整套应用操作。

## 5. 空、加载与错误状态

| 状态 | 展示与动作 |
| --- | --- |
| 首次读取 | 使用紧凑 `ProgressView`，不显示旧数量为零 |
| 空库 | 显示“还没有订阅”，提供“新建订阅”和“打开模板库” |
| 无近期到期 | 保留概况和费用，临期区显示“所选范围内没有到期项目” |
| 数据打开失败 | 显示初始化错误摘要和“打开 Periodic 查看详情”，不提供会失败的写操作 |
| 刷新失败且有旧快照 | 保留旧快照，明确标记“更新失败”及上次成功时间，允许重试 |
| 主记录已删除 | 点击旧快照条目时先刷新；若仍不存在，打开表格视图并提示记录已不存在 |

错误日志只记录阶段、错误类型和数量，不记录订阅名称、备注或金额明细。

## 6. 数据与职责边界

菜单栏使用不可变、可发送的专用快照，不直接持有 SwiftData model 或 `ModelContext`：

```swift
struct MenuBarSubscriptionSnapshot: Sendable, Equatable {
    let generatedAt: Date
    let datasetRevision: Int64
    let activeRecurringCount: Int
    let activeLifetimeCount: Int
    let expiredCount: Int
    let inactiveCount: Int
    let unknownDateCount: Int
    let dueTodayCount: Int
    let upcomingItems: [MenuBarUpcomingItem]
    let currencyForecasts: [CurrencyForecast]
}

protocol MenuBarSnapshotService: Sendable {
    func loadSnapshot(
        referenceDate: LocalDate,
        upcomingDayCount: Int
    ) async throws -> MenuBarSubscriptionSnapshot
}
```

- `MenuBarSnapshotService` 通过现有唯一存储入口读取一致快照。
- 状态分类、临期列表和费用计算调用共享 Domain 规则；服务只负责查询、裁剪和生成展示快照。
- `MenuBarUpcomingItem` 仅携带 ID、短展示所需字段及图片引用，不携带备注和历史明细。
- UI 状态在 `MainActor` 更新；读取任务可取消，并使用 generation 检查防止旧响应覆盖新快照。
- 菜单栏场景与每个主窗口拥有独立展示状态，不共享 `WindowSession`。

## 7. 刷新与一致性

以下事件触发快照失效：

- 应用启动及弹层首次打开；
- 订阅、当前周期或影响费用的字段成功写入；
- 数据包导入或数据集切换完成；
- iCloud 合并批次提交完成；
- 应用回到前台、系统日历日或时区改变；
- 用户切换临期范围、语言、金额显示方式或货币展示偏好。

连续事件合并为一次可取消刷新，不按秒轮询，也不因弹层关闭持续重算全库。跨日刷新使用共享 `Clock` / 本地日历日规则，保证到期当天仍有效且剩余 0 天。

当数据库写入正在进行时，菜单栏继续显示上一份完整快照；只在事务成功且新快照生成后整体替换，不能出现半更新统计。

## 8. 窗口路由

菜单栏动作通过窄的 `AppWindowRouting` 能力请求主窗口，不直接操作某个 `WindowSession`：

```swift
enum MainWindowRoute: Sendable, Equatable {
    case dashboard
    case overview(OverviewRouteFilter)
    case timeline(dueHorizon: DueHorizon)
    case subscriptionDetails(UUID)
    case newSubscription
    case templateLibrary
}
```

- 若已有最近活动主窗口，在该窗口中路由并激活。
- 若没有主窗口，通过带 ID 的 `WindowGroup` 新建窗口并在创建后消费一次性 route。
- 多窗口下不得广播并改变所有窗口的选择或筛选。
- route 携带目标 ID 和值类型筛选，不携带 View、Binding 或 SwiftData model。
- 路由被消费一次后清除；窗口恢复不能重复打开上次详情或新建表单。

## 9. 设置与持久化

设置窗口的“通用”页增加“菜单栏”分组：

- 在菜单栏显示 Periodic：默认开启；
- 默认临期范围：7 / 15 / 30 天，默认 15；
- 在菜单栏显示预估金额：默认开启。

这三项属于设备本地偏好，存入 `UserDefaults` / `@AppStorage` 对应的设置 adapter，不进入 SwiftData 业务库、`.periodicdata` 数据包或 iCloud 同步。视图不能散落读取字符串 key；key、默认值和迁移集中在 `MenuBarPreferences`。

关闭状态项前不需要危险操作确认，但设置页说明：关闭后必须从 Dock、Spotlight 或 Finder 打开 Periodic。若状态项关闭且当前没有主窗口，应用仍保持普通 Dock 行为。

## 10. iCloud、导入和通知联动

- 菜单栏始终展示本机当前已提交数据；不直接查询 CloudKit，也不等待所有设备完成同步。
- iCloud 合并、导入和恢复必须先通过各自事务边界，完成后只发送一次数据版本变化事件。
- 通知调度与菜单栏快照分别消费相同日期规则，菜单栏不创建、取消或代替系统通知。
- AI 不读取菜单栏 UI 状态；从菜单栏进入详情后仍遵循 AI 写操作的提案与确认流程。
- 数据维护锁期间禁用新建动作并说明“数据操作正在进行”，只读旧快照仍可查看。

## 11. 可访问性、本地化与隐私

- 状态项、摘要、每行订阅和底部操作都有明确 VoiceOver 标签、值和提示。
- 日期、金额及相对天数使用当前应用语言和展示偏好；不能把格式化文本反向用于计算。
- 动态字体、长服务名和较大辅助字号下允许弹层增高和内容滚动，不裁掉关键操作。
- 到期和错误状态同时使用文字与图形，不只使用颜色。
- Reduce Motion 开启时取消数字和列表重排动画。
- 弹层会显示订阅名称和可选金额；设置页明确提供隐藏金额开关。订阅名称和金额不写入通知、剪贴板或系统状态项标题，状态项标题最多包含临期数量。

## 13. 测试与验收

### 13.1 自动化测试

- 状态项固定采用今天到期计数，与弹层 7/15/30 天范围互不污染。
- 今天到期、明天到期、范围边界、已过期、停用、终生和无日期记录分类正确。
- 月均和年化按币种分组，不包含终生或不同币种合计。
- 1,000 条订阅下快照输出稳定、可取消，旧 generation 不覆盖新结果。
- 写事务失败时保留旧快照，成功时一次替换全部字段。
- 跨日、跨年、闰日和时区变化后重新计算。
- 主窗口存在、不存在及多个窗口时，route 只被目标窗口消费一次。
- 关闭状态项后数据和主窗口不受影响，重新开启可恢复显示。
- VoiceOver 标签不依赖图标名称或颜色，并包含服务名、日期和相对状态。

### 13.2 验收标准

- **MENUBAR-01**：应用保持正常 Dock 与主窗口行为，同时可通过设置显示或隐藏菜单栏状态项。
- **MENUBAR-02**：点击状态项展示当前有效、异常状态、即将到期和分币种费用信息。
- **MENUBAR-03**：状态项数量固定采用今天到期口径，0 不显示，失败不伪装成 0。
- **MENUBAR-04**：临期列表与首页共享日期规则，今天到期显示 0 天且次日才归为过期。
- **MENUBAR-05**：费用不跨币种相加，终生价格和实际付款不混入周期预估。
- **MENUBAR-06**：点击订阅可激活或创建一个主窗口并打开正确详情，不修改其他窗口状态。
- **MENUBAR-07**：菜单栏不承载编辑、删除、续费、导入和冲突处理。
- **MENUBAR-08**：数据库、导入和同步只在事务成功后触发一次完整快照刷新。
- **MENUBAR-09**：关闭主窗口后状态项继续可用；退出 Periodic 后状态项消失且无后台进程残留。
- **MENUBAR-10**：关闭金额展示后弹层和可访问性文本均不泄露金额。
- **MENUBAR-11**：加载失败、旧快照和维护锁状态有明确结果与恢复动作。
- **MENUBAR-12**：键盘、VoiceOver、增加对比度、减少动态效果和长文本均可正常使用。

## 14. 分阶段落地

1. 已完成：定义 `MenuBarPreferences`、快照值类型和共享 Domain 查询。
2. 已完成：装配可插入的 `MenuBarExtra`，完成空态、加载态和只读摘要。
3. 已完成：接入临期列表、费用速览、数据版本、前台与跨日刷新。
4. 已完成：实现单次主窗口 route、详情跳转、新建、模板库和设置入口。
5. 待后续功能落地：接入导入、iCloud、维护锁和生命周期待处理事件。
6. 部分完成：已覆盖快照口径和偏好回退单元测试；多窗口、性能及完整可访问性验收仍待补齐。

实现顺序先保证口径和路由正确，再增加视觉细节；不能为了菜单栏即时展示而在 View 中直接 fetch SwiftData 或复制首页统计算法。
