# 数据导入与导出规格

> 版本：1.3｜日期：2026-09-24｜状态：V1 已实现。
> 依赖：[需求文档](../requirement.md)、[架构说明](../architecture.md)、[扩展规格总则](README.md)。

## 1. 产品定位

Periodic 只维护一种用户数据交换格式：`.periodicdata` 原生数据包。它用于用户主动备份、迁移到另一台 Mac，以及为后续 iCloud 首次迁移生成安全快照。

CSV 导入导出、外部列映射、复制导入、当前筛选导出和选中项目导出不属于当前产品范围。它们与 iCloud 日常同步没有直接技术复用，且需要额外维护不完整的数据语义、兼容规则和高成本错误处理；除非后续出现明确用户需求，不进入实现计划。

iCloud 同步不是文件导入：日常同步必须使用独立的 mutation journal、tombstone、检查点和字段变更集合，不能把 `.periodicdata` 或 CSV 当作设备间同步协议。

## 2. 当前用户能力

设置窗口的“数据”页面只展示已经可用的两项操作：

1. **导出完整备份**：导出当前 V1 支持的全部业务记录、设置白名单和本地图标。
2. **导入数据**：读取 `.periodicdata`，严格校验后预览，并按稳定 UUID 合并到当前数据集。

File 菜单、首页、表格、时间轴及空态不重复提供入口。设置页不展示 CSV、整体恢复、复制导入或其他尚未实现的占位项。

## 3. V1 数据范围

| 数据 | 是否包含 | 说明 |
| --- | --- | --- |
| subscriptions | 是 | 当前资料、计费类型、自动续费意图和 revision |
| subscription periods | 是 | 保留独立 UUID 和父订阅关系 |
| user templates | 是 | 仅用户模板；内置模板继续随应用分发 |
| custom categories | 是 | 保留稳定 UUID |
| builtin category assignments | 是 | 只保存用户覆盖 |
| local icon assets | 是 | 按 SHA-256 内容哈希去重 |
| settings | 部分 | 仅显式白名单中的显示、币种和菜单栏偏好 |
| notification authorization | 否 | 属于当前设备系统状态 |
| iCloud state and tokens | 否 | 属于同步适配器本地状态 |
| AI Provider、密钥和对话 | 否 | 属于设备本地敏感配置 |

付款、试用/取消计划和变更记录当前尚无对应持久化模型，因此 V1 不声明这些空表。对应模型落地后，数据包必须提升格式版本，并明确旧应用的拒绝或兼容行为。

## 4. 数据包结构

```text
Periodic Backup.periodicdata/
├── manifest.json
├── data/
│   ├── subscriptions.jsonl
│   ├── periods.jsonl
│   ├── templates.jsonl
│   ├── categories.jsonl
│   ├── builtin-category-assignments.jsonl
│   └── settings.json
├── assets/
│   └── <sha256>.<png|jpg>
└── checksums.json
```

- Finder 将 package 显示为单个文档；UTType 为 `local.lhg.periodic.data-package`。
- 时间戳使用 RFC 3339 UTC，业务日期使用 Gregorian `YYYY-MM-DD`。
- 金额使用最小货币单位、币种代码和币种精度，不使用 `Double`。
- 每类记录具有显式 `recordVersion`，关系只使用稳定 ID。
- `checksums.json` 为除自身外的文件记录 SHA-256。校验和用于发现损坏，不用于证明来源可信。

## 5. 导出规则

1. 从单一 `ModelActor` 获取一致的只读值快照。
2. 只导出 V1 明确支持的实体和设置白名单。
3. 内置图标只记录稳定资源名；用户图片读取字节后按内容哈希去重写入 `assets/`。
4. 数据记录使用稳定顺序编码，保证同一快照可重复验证。
5. 生成 manifest 和校验和后进行自校验，再交给系统文件面板保存。
6. 用户取消或写入失败不改变数据库，也不把不完整目标报告为成功。

导出的数据包未加密，确认页必须说明其中可能包含订阅名称、金额、日期和备注。

## 6. 合并导入规则

### 6.1 预览

导入依次执行：

```text
系统文件选择器
    ↓
安全作用域内只读打开
    ↓
验证 package、版本、路径、大小和校验和
    ↓
解析记录并验证字段、图片和引用闭包
    ↓
与当前数据按 UUID 比较
    ↓
展示新增、相同、冲突和图片数量
```

预览不会写入正式数据库或修改图片引用。计划绑定源数据摘要、目标规范化快照摘要和 15 分钟有效期；目标数据变化或计划过期后必须重新预览。

### 6.2 UUID 语义

- UUID 不存在：新增。
- UUID 存在且业务内容相同：跳过。
- UUID 存在且业务内容不同：冲突。
- 名称相同但 UUID 不同：作为两条记录，不按名称自动合并。

当前冲突处理按本次操作统一选择“保留本地”或“使用导入记录”。导入文件中的 revision 不直接覆盖本地 revision；提交后由本地 Store 生成合法版本。

### 6.3 提交

- 所有数据库变化在单一 `ModelContext` 中完成，并只调用一次 `save()`。
- 任一记录失败时 `rollback()`，不得留下部分业务记录。
- 设置导入是用户可单独取消的选项，只应用白名单字段。
- 成功后只发布一次订阅和模板数据变化，使所有窗口刷新。

图片遵循“先保证目标文件存在，再提交数据库引用”的顺序，并跟踪本次实际新建的文件；数据库提交失败或冲突策略未采用对应图片时，在核对正式引用后清理。跨进程崩溃恢复和全应用统一 staging 留到 iCloud 写入协调阶段；在此之前不得声称图片与数据库构成跨文件系统的完全原子事务。

## 7. 安全限制

- 拒绝符号链接、绝对路径、`..`、隐藏路径、未声明文件和目录结构冲突。
- 数据包总大小上限为 100 MB，记录总数上限为 100,000。
- 严格验证 manifest 声明数量、格式版本、日历和导出范围。
- 图片扩展名必须与 PNG/JPEG magic bytes 一致，并通过哈希、10 MB 单文件上限、3,200 万像素上限和可解码性验证。
- 验证订阅与周期、模板与分类及图标引用，不允许孤儿关系。
- 金额精度、周期型/终生字段组合、自动续费字段组合必须通过领域校验。
- 不执行数据包中的 URL、脚本或其他内容，也不因图标引用发起网络请求。
- 文件访问只通过用户授权的系统面板，操作结束即释放安全作用域。

## 8. 与 iCloud 的复用边界

### 8.1 可以复用

- 稳定 UUID、显式格式版本和领域字段校验。
- 完整快照及首次启用 iCloud 前的本地安全备份。
- 图片哈希、内容验证和引用闭包检查。
- 数据摘要和迁移预览所需的计数模型。

### 8.2 不能直接复用

- 数据包快照不能表达离线期间的逐次变更、删除 tombstone 或服务端检查点。
- 统一“保留本地/使用导入”不能满足多设备字段级冲突。
- 数据包 digest 只能保护一次导入计划，不能替代持久化 dataset revision。
- 文件面板授权和 package 编解码不参与 CloudKit 日常上传下载。

因此 iCloud 实现前优先建设：

1. `DatasetMetadataRecord` 与持久化 `storeRevision`。
2. 覆盖所有业务 Store 的 `DatabaseWriteCoordinator` 和维护锁。
3. `sync_mutations` journal、幂等 mutation ID 和 tombstone。
4. 独立于 UI 和 CloudKit 的纯领域合并器。
5. 图片 staging、失败补偿和无引用资源回收。
6. 用于首次迁移的候选数据库、安全切换和回滚快照。

这些能力完成后，可按需要复用到数据包导入；不为了完善低频导入功能而延后 iCloud 主路径。

## 9. 当前不实现的能力

以下能力不显示在设置或其他界面，也不作为当前版本验收项：

- CSV 导入与导出及外部列映射；
- 复制导入和为根记录重建 UUID；
- 当前筛选、选中项目或仅模板导出；
- 逐条、逐字段的数据包冲突 UI；
- 用户主动触发的整体替换恢复；
- 最近导入操作列表；
- 为超出当前资源上限的数据提供流式超大规模模式。

其中 staging 恢复、字段级合并、维护锁和持久化 dataset revision 会在 iCloud 阶段作为内部基础设施实现；是否随后开放为独立数据功能，由真实用户需求决定。

## 10. 验收标准

- **EXCHANGE-01**：设置页只显示当前可用的导入和导出操作。
- **EXCHANGE-02**：完整导出包含 V1 声明的所有实体、设置白名单和用户图片。
- **EXCHANGE-03**：损坏校验和、危险路径、不兼容版本、坏图片和断裂引用在写入前被拒绝。
- **EXCHANGE-04**：导入预览前不修改正式数据库或图片引用。
- **EXCHANGE-05**：UUID 新增、相同和冲突计数准确；名称相同不自动合并。
- **EXCHANGE-06**：计划过期或本地数据变化后不能提交旧预览。
- **EXCHANGE-07**：批量数据库提交失败时不保留部分记录。
- **EXCHANGE-08**：导入成功后所有相关窗口只收到一次数据刷新。
- **EXCHANGE-09**：系统权限、AI 密钥和 iCloud 状态不进入数据包。
- **EXCHANGE-10**：数据包逻辑不作为 CloudKit 日常同步协议。
