# 拼车订阅

日期：2026-10-01。此版本提供本地人数与报价管理，支持车主和参与者；成员共用订阅的计费类型、周期、开始日和到期日。

## 当前配置

- 拼车是独立于周期订阅/终生购买的费用组织方式，不新增计费类型。
- 人数包含自己，至少两人。自己固定为“我”；其余成员分别保存 UUID 和昵称，车主记录成员价格。昵称可重复，UUID 在同一拼车配置内不可重复。
- `Subscription.money` 是我的约定费用，既是“我”这一行的唯一金额来源，也是个人月均/年化预估的依据。拼车人数不增加订阅数量。
- 车主填写订阅总价、我的价格和每位其他成员价格，成员金额可不同，允许零元，价格留空不能保存。
- 参与者只设置人数和我的价格，不需要填写订阅总价、其他成员昵称或价格；新建参与者配置仅用成员标识保存人数，其他成员金额为空，不计算成员合计。
- 旧配置及历史中缺失的成员价格继续可读取，不推导为零元；车主编辑保存前补填。参与者旧配置已有的成员价格与订阅总价保留，界面只展示个人价格和人数；切换身份不清空价格草稿。
- 订阅总价、个人费用与其他成员报价共用币种；修改币种后按新币种精度重新校验，不执行换汇。金额使用现有最小货币单位；合计溢出拒绝保存。
- 成员合计不必等于订阅总价。差额只是约定报价与订阅总价之差，不是已实现收入或实际净成本。
- 表单使用独立草稿。添加或移除成员仅修改草稿；保存才写入，取消恢复原配置。关闭拼车删除当前配置，保留历史。
- 车主可直接移除指定成员，其余成员的 UUID、昵称和金额保持不变；只剩一名其他成员时隐藏移除，人数下限为两人。参与者通过人数步进控件调整人数，减少人数保留前面的成员标识。

## 界面布局

- 计费与价格分区提供“多人拼车”开关。启用后，拼车区第一行统一放置身份分段控件和币种菜单，币种不在上方和各成员处重复显示。
- 车主第二行并排放置订阅总价与我的价格，使用等宽分栏及 112 点价格框；我的价格独立于其他成员输入组，不保留昵称或移除占位。价格口径沿用上方计费周期。
- 下方“成员价格”标题行显示总人数（含我）与带加号的添加成员操作。其他成员采用单行“昵称、价格、×”组合输入框，使用原生自适应网格，最小列宽 170 点，标准编辑器宽度可横向排列三组；不足时自动换行。成员价格框为 72 点，昵称弹性伸缩，长输入使用原生文本框滚动。
- 组合输入框使用语义化背景、细边框和统一焦点描边，昵称与价格保留独立的键盘焦点、可访问性标签及币种提示；不增加卡片标题或重复币种。价格占位按币种精度展示 0、0.00 或 0.000，不表示自动填入零元。
- 移除使用价格旁的 × 图标按钮，提供“移除成员 + 昵称”的可访问性标签与帮助提示；只剩两人时隐藏无效操作。添加成员追加独立 UUID 的空价格草稿并聚焦昵称，金额右对齐。下方有效期仍统一设置。
- 参与者在身份与币种行下方，将人数和我的价格并排展示；人数文字与原生步进按钮分开布局，按钮宽度为 20 点，避免带标签的步进控件撑宽整个表单。步进按钮保留人数标签与当前值的可访问性语义，不提供订阅总价、其他成员价格或添加成员入口。
- 车主详情采用成员价格列表与价格汇总两列，汇总列至少 420 点；空间不足时上下排列，整体可滚动。汇总保留我的价格，订阅总价、成员价格合计和价格差额在同一行按三列等宽横向排列，标签与金额左对齐，差额说明紧随该行，长金额允许换行而不裁切。差额为合计减订阅总价，不称为收入。旧配置价格不完整时提示补填，不呈现部分合计。未填写与零元分别显示。
- 参与者详情与历史只展示我的价格和人数，不提示其他成员价格缺失；续费同样只说明个人价格与实际支付的关系。
- 当前拼车和历史快照复用同一价格布局，历史页保留当期日期。颜色遵循系统浅色/深色语义，操作使用原生按钮。
- 拼车详情提供周期菜单，包含“当前方案”和各期完整起止日期；当前拼车启用时默认优先选择与当前订阅日期一致的快照，其次为今天所在期，再次为最近一期。关闭当前拼车后，只要历史还有拼车记录，仍保留拼车页入口，并优先选择今天所在期。
- 周期菜单旁提供“添加周期”和“编辑本期”，编辑直接在拼车页展开，底部统一取消/保存。日期并排，成员沿用横向输入组；车主可添加或移除成员，参与者只调整人数与我的价格。价格汇总随草稿更新，输入不完整时显示校验提示，不展示伪造合计。编辑时暂停页面切换、当前方案编辑和关闭，保存失败保留全部输入。
- “编辑当前方案”保留独立入口，用于后续默认配置；“编辑本期”只保存选中周期的日期、个人价格与拼车快照，不修改当前默认配置、其他周期或任何付款。
- 添加周期从最近一条拼车历史复制身份、成员标识及各自价格，创建新的周期 UUID；预置周期默认从前期结束次日起接续，结束为开始日增加周期月数后减一天。自定义日期继承前期自然日数。无历史时采用当前方案并从今天开始：固定周期按周期月数计算结束，自定义周期继承当前配置的自然日数，当前配置日期不完整时预置为同日结束并允许手动调整。与其他记录重叠时明确确认后才保存。新增只记录约定周期，不推进当前到期日或登记付款；终生历史保留原有记录语义。

## 付款与历史

- 报价不是付款证明。新增、编辑成员不生成付款或收款。
- 沿用当前应用的到期续费确认入口。拼车表单以“拼车续期确认”表达此选项；应用不会自动扣款或推进周期。
- 续费实际支付默认：车主取订阅总价，参与者取我的费用。补录消费也使用相同默认值；用户可明确修改实际金额与币种。
- 新建完整周期、显式追加周期和续费保存当期拼车快照。当前成员、身份和金额改变，不修改既有快照。
- 自定义续费改变计费周期时，按周期月数折算当期报价和订阅总价，保留未知报价；当前未来报价继续不变。
- 普通周期表手动新增仍以当前拼车配置预填快照，普通周期表编辑保留原拼车快照。拼车页本期编辑可以明确替换该期成员及价格，所有金额按所选币种精度统一校验；历史币种不能与该期成员报价不一致。普通周期编辑不改变成员或其币种。
- 周期表提供“拼车报价”入口，即使当前关闭拼车仍可查看历史。
- 删除周期同时删除其拼车快照，付款仍按原有规则解除关联并保留。删除订阅删除全部当前拼车配置及快照。
- 复制只预填当前配置，为成员生成新 UUID，不复制周期、付款历史。
- 终生拼车同样记录一次性约定报价，继续不续费、不提醒、不参与周期预估。

收款登记、已收/未收、成员独立到期日、成员换座中途按天分摊及实际净支出不属于此版本。车主向服务商登记的订阅实际付款属于实际支出，不减去尚未记录的成员报价。

## 架构与数据兼容

- Domain：`SubscriptionSharingPlan`、`SubscriptionSharingMember` 与身份枚举，集中验证并计算合计、复制和周期折算。
- 持久化：新增 `SubscriptionSharingRecord`，以订阅或周期为所有者，保存格式版本为 1 的 Codable 值。成员没有独立生命周期或联系人目录，随配置整体原子保存。订阅与周期拥有不同的所有者键，允许两种实体具有相同 UUID。
- 拼车周期表单使用独立编辑会话持有非可选草稿。取消或保存只移除当前会话；退出期间仍存活的控件绑定继续访问原草稿，后续编辑建立新会话，旧控件回调不能恢复编辑或修改新草稿。
- 写入通过已有 Store actor 和同一 ModelContext。当前配置修改递增所属订阅 revision，多窗口旧草稿被拒绝；复合写入失败全部回滚。
- SwiftData 增加 V6，V5→V6 为新增实体的轻量迁移；旧订阅没有拼车记录，不推导成员或付款。
- `.periodicdata` 升级为 V5、最低读取版本为 5。当前配置和周期快照嵌入对应父记录，合并比较包含拼车字段，复用父记录的冲突策略及幂等逻辑。
- V1–V4 数据包缺失拼车字段时读取为普通订阅；旧版格式声明不能携带拼车字段。新版本不允许声明过低的读取版本，避免旧应用忽略拼车数据。
- 不增加外部依赖、网络能力、账号或系统权限。

## 验证

单元测试覆盖参与者仅填个人价格、车主成员价格必填与零元、人数调整、身份切换草稿保留、旧配置缺价读取兼容，以及币种精度、溢出、重复成员、草稿隔离、身份付款默认值、个人预估、历史保留、事务回滚、重复续费、备份往返与冲突、旧版磁盘库迁移。周期编辑回归覆盖本月五人/下月四人独立保存、本期价格纠正、旧接口保留快照、月末/闰年/跨年日期衔接、自定义覆盖、重叠确认、取消无写入、并发冲突保留草稿、保存期间重复提交，以及新增/编辑在取消和保存后的控件绑定可继续读写、旧会话与已保存数据及新会话隔离。按项目约束禁止 UI 测试，仅通过项目脚本运行单元回归与构建检查；原生界面交互不声明为测试通过。
