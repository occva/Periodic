# Periodic 1.0.1

本次小版本优化设置与模板界面，面向 macOS 26 或更新版本，仅支持 Apple silicon（arm64）。构建号为 2。

- 精简通用与更新设置页，移除冗余说明和构建号展示，保留设置控件及必要的错误、权限和重启提示。
- 模板分类栏改为不透明背景，保留原有侧栏样式、图标、选中状态与分类操作。
- 缩减模板选择弹窗左上角的空白，使用紧凑标题和系统原生搜索框。
- 去掉“导入数据”“导出完整备份”“本地图片”“Apple 搜索”按钮末尾的省略号，同步英文文案。

## 更新与安装

已安装 1.0.0 的用户可通过应用菜单或“设置 > 更新”中的“检查更新”获取此版本。更新安装后自动重启，保留已有本地数据。

手动安装时，下载 `Periodic-1.0.1.dmg`，将 Periodic 拖入“应用程序”，然后从“应用程序”启动并推出磁盘映像。

此版本使用临时代码签名，未经 Apple 公证。如果首次打开被系统阻止，在确认下载来自本仓库后，在终端执行：

```bash
xattr -rd com.apple.quarantine /Applications/Periodic.app
```

如果提示权限不足，执行：

```bash
sudo xattr -rd com.apple.quarantine /Applications/Periodic.app
```

然后重新打开 Periodic。该命令只移除下载隔离标记，不代表应用已获得 Apple 签名或公证。

## 隐私

订阅及付款数据保存在本地。更新检查与下载连接 GitHub 发布服务，不发送订阅、付款、图片或备注。自动检查默认关闭，可在“设置 > 更新”中开启。

更新包与更新源使用 Sparkle Ed25519 签名校验。文件名带 `-local` 的包仅用于本地验证。
