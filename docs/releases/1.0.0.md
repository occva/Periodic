# Periodic 1.0.0

Periodic 首个正式版本，面向 macOS 26 或更新版本，仅支持 Apple silicon（arm64）。

- 原生管理周期订阅与终生购买，提供首页、时间轴和表格视图。
- 分别记录报价、周期和实际付款，支持拼车订阅、到期提醒和菜单栏速览。
- 支持 `.periodicdata` 数据包导入与导出、模板、图标以及中英文界面。
- 新增应用菜单“检查更新…”与“设置 > 更新”，支持签名校验、安装后自动重启及可选的自动更新。
- 提供拖入 Applications 即可安装的 DMG 窗口，更新应用保留已有本地数据。

## 安装

下载 `Periodic-1.0.0.dmg`，将 Periodic 拖入“应用程序”，然后从“应用程序”启动并推出磁盘映像。

此版本使用临时代码签名，未经 Apple 公证。如果首次打开被系统阻止，在确认下载来自本仓库后，在终端执行：

```bash
xattr -rd com.apple.quarantine /Applications/Periodic.app
```

如果提示权限不足，执行：

```bash
sudo xattr -rd com.apple.quarantine /Applications/Periodic.app
```

然后重新打开 Periodic。该命令只移除下载隔离标记，不代表应用已获得 Apple 签名或公证。

## 隐私

订阅及付款数据保存在本地。更新检查与下载连接 GitHub 发布服务，不发送订阅、付款、图片或备注。自动检查默认关闭，可在“设置 > 更新”中开启。

更新包与更新源使用 Sparkle Ed25519 签名校验。文件名带 `-local` 的包仅用于本地验证。
