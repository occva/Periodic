# 大数据与多时间点测试

## 目标

使用同一批订阅数据在不同“今天”下验证状态、临期范围和费用统计，避免测试依赖运行测试当天的系统日期。

## 数据集

- 默认生成 240 条订阅，名称和业务字段可区分。
- 到期日覆盖基准日前后 3 年，并包含 `-31/-30/-8/-7/-1/0/1/7/8/15/30/31` 等关键边界。
- 覆盖全部服务分类、管理状态、计费类型和支持的币种。
- 同时包含周期订阅、终生项目、日期未知项目和停用项目。
- 金额按币种精度使用最小货币单位生成，不跨币种合计。

## 自动化验证

`SubscriptionAnalyticsTests` 在多个基准日上验证：

1. 五类状态互斥且总数守恒。
2. 时间向前推进时，过期数量不减少、有效周期数量不增加。
3. 7/15/30 天临期范围包含今天和第 N 天，排除昨天与第 N+1 天。
4. 费用统计的参与条目数与按币种、按分类分组后的数量一致。
5. 240 条数据可在一次存储操作中写入并完整读取。

## 可视化样本

开发构建可运行 `./script/build_and_run.sh --sample-data`。该模式同时启用内存数据库和测试数据参数，不读取或修改正式用户数据库；退出应用后样本自动丢弃。
